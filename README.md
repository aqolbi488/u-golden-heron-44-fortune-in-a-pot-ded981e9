A kind, funny fortune for the houseplant on the windowsill — a small prediction of sunny leaves, timely watering, and outgrowing its spot. The program writes one fixed fortune line to `/output/entry.txt`, deterministically, on every run.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18+ (which runs TypeScript as-is). No dependencies, no network calls, no secrets.
